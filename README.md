# MineCrafft

一个网页版野外生存游戏 Demo。单文件 HTML + Canvas 实现，无需安装任何依赖，双击 `index.html` 即可在浏览器中运行。

## 如何运行

打开 Finder，进入本仓库目录，双击 `index.html`，会自动用默认浏览器打开。

## 操作方式

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动角色 |
| `E` | 与附近的物体互动（砍树、采浆果、喝水、添柴、拾取/放置围栏、使用医疗包） |
| `F` | 装备武器后攻击附近的怪物 |

## 玩法说明

- **四项生存数值**：饥饿、口渴、体力、体温，会随时间下降，任意一项归零即死亡结算。
- **生命值**：被怪物攻击会掉血，归零则被怪物杀死。
- **资源采集**：
  - 🌳 砍树获得木材，用于给篝火添柴
  - 🫐 采摘浆果恢复饥饿
  - 💧 池塘边喝水恢复口渴
  - 🩹 医疗包恢复生命值（用后会重新长出）
- **昼夜循环**：夜晚气温更低，体温下降更快；靠近点燃的篝火可以取暖并缓慢恢复体力。
- **战斗与防御**：
  - 地图上有一把🗡️武器，拾取后可用 `F` 攻击怪物（3 下击杀）
  - 怪物只在夜晚刷新，会主动靠近玩家造成伤害
  - 收集🚧围栏并放置在篝火周围的卡位，可以挡住怪物靠近

## 项目状态

目前是一个可玩的原型 Demo，用于快速验证生存类玩法的核心循环，尚未涉及存档、多人、程序生成地图等功能。
